Bienvenido a la Documentación de la API de PHC

Esta plataforma reúne todos los módulos que integran el ecosistema PHC: cuentas, empresas, candidatos y ofertas de empleo. A través del menú lateral puedes navegar entre cada sección de la API y consultar sus endpoints, esquemas de datos, parámetros y ejemplos reales de uso.

La documentación está diseñada para ser clara, modular y fácil de integrar, tanto en frontends como en servicios externos.

¿Qué encontrarás aquí?

  • Guías por módulo: operaciones principales (GET, POST, PUT, DELETE).
  • Estructuras de datos: modelos, relaciones y validaciones.
  • Ejemplos listos para copiar y usar.
  • Requisitos de autenticación y uso de tokens.
  • Flujos recomendados de integración.

Sobre esta API

PHC es una API REST diseñada para ser consistente, escalable y compatible con cualquier cliente HTTP. Todos los módulos comparten una estructura homogénea para facilitar la implementación y garantizar confiabilidad.
